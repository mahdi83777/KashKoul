# Kashkoul Academy — website

Single-page static site. No framework, no dependencies; a 60-line Node script assembles the HTML partials.

```
academy/
├── index.html            GENERATED — do not edit (built from src/)
├── src/
│   ├── index.html        page shell: <head>, then one @include per section
│   └── partials/
│       ├── header.html · hero.html · instruments.html · how-it-works.html
│       ├── why.html · teacher.html · visit.html · footer.html
│       └── icons/        whatsapp.svg, logo-hero.svg (the inline logo, split into 3 masked parts)
├── css/
│   ├── main.css          entry point — imports everything below, in cascade order
│   ├── base/             tokens (colours, fonts, layout vars) · fonts · reset · utilities
│   ├── components/       buttons · header (nav, burger, mobile menu)
│   └── sections/         hero · hero-notebook · hero-intro (opening animation) · instruments ·
│                         how-it-works · manifesto · teacher · visit · footer
├── js/
│   ├── main.js           entry point — wires the modules below
│   ├── config.js         WhatsApp number + message, the instruments list   ← most edits happen here
│   ├── whatsapp.js       wa.me links for every [data-wa] element
│   ├── instruments.js    renders the cards from config
│   ├── hero.js           cursor reveal / parallax + the opening sequence
│   ├── nav.js            solid header on scroll, logo → top, mobile menu
│   ├── credits.js        courtesy photo-credit line in the footer (from config)
│   └── motion.js         reduced-motion flag + small async helpers
├── tools/build.js        src → index.html  (--watch, --serve, --dist)
├── _headers              Netlify security + cache headers (copied into dist/)
├── dist/                 GENERATED by `npm run dist` — what Netlify publishes (git-ignored)
├── package.json          npm run build · dev · dist
└── assets/
    ├── fonts/            Bricolage Grotesque (EN), Fustat (AR + body)
    ├── logo/             logo lockups (SVG) + favicon
    ├── patterns/         brand patterns (SVG)
    └── photos/           photos + CREDITS.md (CC placeholders until studio photos are ready)
```

## Working on it

```
npm run dev      # builds, watches src/, serves http://localhost:8765  (PORT=9000 npm run dev to change)
npm run build    # one-off build → index.html
```

CSS and JS are loaded directly by the browser (`@import` / ES modules), so they need no build — only the HTML partials do.
Because of ES modules the site must be served over HTTP (not opened as a `file://`).

## Common edits

| Change | Where |
|---|---|
| Add / reorder / rename an instrument | `js/config.js` → `INSTRUMENTS` (card colour = `color`, photo = `assets/photos/<img>`) |
| WhatsApp number or prefilled message | `js/config.js` |
| Section copy | `src/partials/<section>.html`, then `npm run build` |
| Colours, fonts, nav height | `css/base/tokens.css` |
| Opening animation timings | `css/sections/hero-intro.css` (each act is one `animation:` line) |
| Placeholders still to fill | `[Your name]`, `[X] years`, `[ensembles]` in `teacher.html`; `[street]` in `visit.html` |

## Deploy — Netlify

`kashkoul.org` is hosted on Netlify. Two ways to ship:

**Automatic (recommended):** connect this Git repo to the Netlify site once (Site configuration → Build & deploy →
Link repository). `netlify.toml` at the repo root tells Netlify to run `npm run dist` inside `academy/` and publish
`academy/dist/`. Every push to `main` then deploys in ~30 s.

**Manual:** `npm run dist`, then drag the `academy/dist/` folder onto the site's *Deploys* page.

`dist/` contains only runtime files (`index.html`, `css/`, `js/`, `assets/`, `robots.txt`, `sitemap.xml`, `_headers`)
and is git-ignored. `_headers` sets the security and cache headers.
